Data flow for Security Copilot

Everything stays inside the Microsoft Security trust boundary. All requests are encrypted over HTTPS.

+ Azure OpenAI (LLM)
Plugins: Microsoft & third-party security products – grounding with your logs, alerts, incidents & policies
1User prompts from security products are sent to Copilot
2Copilot accesses plugins for pre-processing (grounding)
3Copilot sends the modified prompt to the LLM
4Copilot receives the LLM response
5Copilot accesses plugins for post-processing
6Copilot sends the response and app commands back to the security products

Customer data is not stored outside the compliance boundary or used to train foundation models. The Azure OpenAI instance is maintained by Microsoft; OpenAI has no access to the data or the model.
